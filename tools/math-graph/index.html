Welcome to MathGraph! You can plot:

  • **Explicit Functions**: `y = x^2`, `y = sin(x)`
  • **Implicit Equations**: `x^2 + y^2 = 9` (Circle)
  • **Polar Coordinates**: `r = 2 * sin(5*theta)`

Controls:
- Drag to Pan
- Scroll to Zoom
- Use the provided keyboard for symbols.
