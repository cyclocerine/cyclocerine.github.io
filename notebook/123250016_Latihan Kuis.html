Metode VLSM (Variable Length Subnet Masking)

1. Deskripsi Masalah

Dilakukan pembagian jaringan 192.168.25.0 menggunakan metode VLSM (Variable Length Subnet Masking) untuk mengakomodasi kebutuhan host pada beberapa laboratorium dengan rincian sebagai berikut:

  • Lab IoT: 120 Host
  • Lab Jaringan: 87 Host
  • Lab Komputasi: 12 Host

2. Tabel Perhitungan Subnetting

Gedung / Lab Host Subnet Mask NA Range Host BA
Lab IoT 120 255.255.255.128 192.168.25.0 192.168.25.1 - 192.168.25.126 192.168.25.127
Lab Jaringan 87 255.255.255.128 192.168.25.128 192.168.25.129 - 192.168.25.254 192.168.25.255
Lab Komputasi 12 255.255.255.240 192.168.26.0 192.168.26.1 - 192.168.26.14 192.168.26.15

3. Konfigurasi Router (Cisco CLI)

Berikut adalah perintah konfigurasi pada router untuk menetapkan IP address pada interface dan mengaktifkan layanan DHCP server:

Router(config)# int fa0/0

Router(config-if)# ip address 192.168.25.1 255.255.255.128

Router(config-if)# no shut

!

Router(config)# int fa1/0

Router(config-if)# ip address 192.168.25.129 255.255.255.128

Router(config-if)# no shut

!

Router(config)# int fa6/0

Router(config-if)# ip address 192.168.26.1 255.255.255.240

Router(config-if)# no shut

!

Router(config)# ip dhcp pool IOT

Router(dhcp-config)# network 192.168.25.0 255.255.255.128

Router(dhcp-config)# default-router 192.168.25.1

!

Router(config)# ip dhcp pool JARINGAN

Router(dhcp-config)# network 192.168.25.128 255.255.255.128

Router(dhcp-config)# default-router 192.168.25.129

!

Router(config)# ip dhcp pool KOMPUTASI

Router(dhcp-config)# network 192.168.26.0 255.255.255.240

Router(dhcp-config)# default-router 192.168.26.1
